**MT 连点器**不仅能重复点击，还能结合画面中的图片、颜色和文字决定下一步操作。适合日常重复任务、界面测试和需要连续操作的场景。

## 主要功能

### 👆 智能连点
- 连续点击、多位置点击与自定义执行节奏。
- 适合固定位置、重复频繁的触摸操作。

### 🖐️ 手势操作
- 单击、双击、长按。
- 滑动、拖拽和多点触摸。
- 可组合不同动作完成连续任务。

### 👁️ 找图、找色、找字
- 根据图片查找目标位置。
- 根据指定颜色辅助判断。
- 识别画面文字，帮助决定下一步。
- 支持针对指定区域进行识别。

### 🔁 自动操作流程
把画面识别与触摸操作连接起来，例如等待指定内容出现后，再执行预设动作。

### 📱 悬浮控制与输入体验
- 通过悬浮入口查看和管理任务。
- 适配横竖屏和浅色、深色界面。
- 支持系统键盘、中文输入与常用编辑操作。

## 适用场景

| 需求 | MT 连点器能帮你 |
| --- | --- |
| 重复点击 | 自动完成连续或多位置点击 |
| 重复手势 | 依次执行长按、滑动等动作 |
| 等待指定画面 | 使用找图、找色辅助判断 |
| 根据文字继续 | 利用文字识别辅助下一步 |
| App 界面测试 | 重复执行预设操作 |
| 想随时控制任务 | 使用悬浮入口进行管理 |
